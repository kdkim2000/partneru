# OpenAI Cyber Deployment Practitioner

Codex Security(Daybreak)를 활용한 방어적(defensive) 사이버보안 워크플로우를 다루는 과정입니다. 보안 신호를 검증된 근거와 리뷰 가능한 조치로 전환하는 방법, 범위가 한정된(bounded) 평가/파일럿 설계, 거버넌스와 운영 모델, 경영진 대상 가치 스토리 작성까지 다룹니다. Codex Expert, API Expert 트랙에 공통으로 포함되는 과정입니다. 총 7개 차시(강의 영상 7편 + 강의 노트 7편)로 구성되어 있으며, 마지막 차시는 최종 시험입니다.

> Daybreak/Codex Security는 인가된 방어 목적의 워크플로우이며, 모델 접근권 판매, 공격적(offensive) 보안 훈련, 자동 원격 조치(remediation) 보장이 아닙니다. 모든 차시에서 휴먼 리뷰, 고객 거버넌스, 최종 의사결정권이 고객에게 있음을 전제로 합니다.

## 차시별 핵심 내용

### 01 — Codex Security Workflow Patterns

Codex Security가 Daybreak 워크플로우에서 하는 역할을 배웁니다. 위협 모델링부터 재검증(revalidation)까지의 라이프사이클, 보안 스캔·심층 스캔·코드 변경 보안 리뷰·발견사항 수정 및 검증이라는 4가지 플러그인 워크플로우 패턴, 범위·컨텍스트·인가·근거 경계를 설정하는 방법을 다룹니다.

### 02 — Bounded Evaluation and Pilot Design

"모든 걸 테스트하자"가 아니라 인가된 워크플로우 하나로 범위를 좁힌 첫 평가를 설계하는 방법을 배웁니다. 파일럿 헌장(범위, 리뷰어, 근거 기대치, 중단 조건, 에스컬레이션 경로)을 정의하고, 정확성·근거·노이즈·패치 품질·리뷰 부담·수정 시간·수용률·회귀 신뢰도로 구성된 품질 스코어카드를 만듭니다.

### 03 — Cyber Governance and Operating Model

고객이 Daybreak와 Codex Security를 통제되고 반복 가능한 워크플로우로 사용할 운영 모델을 갖추었는지 평가합니다. 인가된 방어 워크플로우, 고객 소유 자산, 승인된 환경, 지정된 리뷰어라는 최소 준비 조건을 확인하고, 진행/중단/에스컬레이션/확장 여부를 판단합니다.

### 04 — Cyber Value Story & Executive Readout

범위가 한정된 Daybreak/Codex Security 증거를 CISO가 신뢰할 수 있는 가치 스토리로 전환합니다. 출력·근거·고객 의사결정·가치 신호·증명 공백(proof gap)을 구분하고, 공포 기반 판매나 과장된 자동화 주장 없이 사실 기반 언어로 임원 보고(executive readout)를 작성합니다.

### 05 — Cyber Application Practice

가상 고객 Harborline Bank 사례를 통해 첫 신호부터 파트너 안전 추천까지 전체 과정을 실습합니다. 고객의 사이버 페르소나와 워크플로우 병목을 진단하고, 범위가 한정된 Codex Security 평가를 설계하며, 근거를 해석해 다음 조치와 담당자를 명시한 추천안을 작성합니다.

### 06 — Cyber Lab: Northstar Financial

가상 금융회사 Northstar Financial의 실제 시나리오(릴리스 3일 전, 62건의 미해결 발견사항, 인가 범위가 제한된 PR 리뷰)를 바탕으로 250~400단어 분량의 고객 보안 추천서를 작성하는 실습 랩입니다. 승인된 범위와 휴먼 리뷰를 유지하면서 근거 기반 판단(입증됨/합리적 추론/미입증)을 내리는 연습입니다.

### 07 — Final Exam

전체 과정 내용을 종합하는 20문항 객관식 시험입니다 (16문항 이상 정답 시 통과).
