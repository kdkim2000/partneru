# Codex Solutions Practitioner

소프트웨어 딜리버리 워크플로우의 반복적인 마찰(리뷰, 테스트, 현대화, 문서화, 온보딩, 유지보수 등)을 근거로 Codex 기회를 판별하고, 세일즈 언어로 포지셔닝·가치 제시·신뢰/거버넌스 대화를 이끄는 세일즈 과정입니다. Codex Expert 트랙의 핵심 과정입니다. 총 6개 차시(강의 영상 6편 + 강의 노트 6편)로 구성되어 있으며, 마지막 차시는 최종 시험입니다.

## 차시별 핵심 내용

### 01 — Codex Opportunity Fit

AI 코딩이나 개발자 생산성을 언급하는 모든 고객이 Codex 논의에 준비된 것은 아니라는 전제에서, 반복되는 SDLC 마찰(리뷰, 테스트, 현대화, 문서화, 온보딩, 품질)과 구체적이고 검증 가능한 평가 태스크로 정의될 수 있는지를 판단합니다. Codex Opportunity Fit Lens(반복 통증, 비즈니스 영향, 이해관계자 소유권, 준비도, 반복 가능한 워크플로우)로 기회를 진행/추가 디스커버리/타 경로 라우팅/보류/실격 중 하나로 분류하는 추천안을 작성합니다.

### 02 — Codex Positioning

Codex를 단순 코딩 도구가 아니라 SDLC 전반의 딜리버리 마찰을 해결하는 솔루션으로 포지셔닝합니다. ChatGPT Chat(협업), ChatGPT Work(위임형 지식 업무), Codex(소프트웨어 엔지니어링), API(제품 내재화)의 역할을 구분하고, 기술/비즈니스 이해관계자에 맞춘 Codex 포지셔닝 추천안을 작성합니다.

### 03 — Codex Value & Use Cases

"Codex는 개발자가 코드를 더 빨리 쓰게 해준다"는 기능 수준 설명을 넘어, 릴리스 지연·엔지니어링 오버헤드·현대화 압박·리뷰 병목 같은 비즈니스 성과와 연결된 가치를 전달합니다. 리뷰·테스트·디버깅·문서화·온보딩·유지보수·현대화·협업 마찰에서 고가치 SDLC 유즈케이스를 식별해 Codex 가치 내러티브를 작성합니다.

### 04 — Codex Trust, Security, and Adoption Conversations

엔터프라이즈 고객은 생산성보다 "AI 지원 엔지니어링 작업이 조직의 기존 빌드/리뷰/배포/유지보수 방식 안에서 책임감 있게 작동하는가"를 묻습니다. Codex를 무제한 AI 자율성이 아닌 통제된(governed) 엔지니어링 가속으로 포지셔닝하고, 신뢰/거버넌스/도입 우려에 셀러 수준으로 대응하며 기술 전문가 개입 시점을 판단합니다.

### 05 — Selling Codex Application Practice

가상 고객 Aureon Systems(Velocity Horizon 이니셔티브, PR 리뷰/릴리스 준비도 불일치 문제)와의 시나리오를 통해 엔지니어링 워크플로우 문제 명확화, 거버넌스 우려 대응, 임원 가치 압박 대응, 다음 단계 추천을 연습합니다.

### 06 — Final Exam

전체 과정 내용을 종합하는 20문항 객관식 시험입니다 (16문항 이상 정답 시 통과). 각 문항 해설에 근거가 된 차시가 명시되어 있습니다.
