## 차시별 핵심 내용

### 01 — From Qualified Opportunity to Deployment Plan

세일즈가 인계한 검증된 기회를 배포 계획의 출발점으로 전환하는 방법을 다룹니다. 핸드오프 근거를 검토하고, 배포 문제 정의와 성공 기준을 세우고, 이해관계자·범위·시작 방식(starting motion)을 확정하여 ChatGPT Deployment Brief를 작성합니다.

### 02 — Plan for Success

배포 준비가 된 기회를 30일 실행 계획으로 전환합니다. 론칭 범위, 우선 워크플로우, 론칭팀 역할, KPI, 거버넌스 체크포인트를 정의하여 워크스페이스 셋업과 사용 사례 활성화로 이어지는 성공 계획을 만듭니다.

### 03 — Set Up Your Workspace

승인된 배포 계획을 워크스페이스 요구사항으로 전환합니다. 접근 권한, SSO/SCIM 프로비저닝, 역할·그룹, 앱/플러그인/Workspace Agent 승인 여부, 모니터링·거버넌스 증거를 점검하여 Workspace Configuration Readiness Checklist를 만듭니다.

### 04 — Design Use Cases for Activation

배포 목표에 맞는 후보 워크플로우를 평가하고 우선순위를 정해 활성화 준비를 합니다. 대상 사용자 그룹, 기대 성과, 성공 신호, 활성화 요구사항과 리스크를 정리한 Use Case Activation Plan을 작성합니다. (동반 워크시트: DC4-1.3)

### 05 — Enable Users and Drive Adoption

사용자가 승인된 워크플로우를 실제 업무에 적용하도록 돕는 User Enablement and Adoption Plan을 설계합니다. 도입 장벽 파악, 그룹별 인에이블먼트 요구사항, 커뮤니케이션 계획, 챔피언·지원 체계, 리스크 대응 방안을 다룹니다.

### 06 — Activate, Measure, and Scale

실제 활성화된 워크플로우의 채택·참여 신호와 초기 가치 증거를 검토하여 계속(continue), 조정(adjust), 확장(expand), 중단(pause) 중 하나를 권고하는 Activation Review and Expansion Plan을 작성합니다.

### 07 — Scaling ChatGPT Across the Organization

앞선 활성화 증거를 바탕으로 조직 전체로 도입을 확산하는 전략을 수립합니다. 확장 우선순위, 소유권과 거버넌스, 인에이블먼트·지원 요구사항, 성장에 따른 리스크를 평가하여 ChatGPT Organizational Scaling Strategy를 만듭니다.

### 08 — Deploying ChatGPT Application Practice

가상 고객 Kestrel Manufacturing(글로벌 제조업체)과의 시나리오를 통해 라이선스 구매 이후 첫 활성화 진입점을 좁히고, 가장 중요한 준비도/거버넌스 이슈를 식별하며, 도입 우려에 대응하는 실전 연습입니다. 기술 구현이 아닌 배포 기획 수준의 대화 연습입니다.

### 09 — Final Exam

전체 과정 내용을 종합하는 20문항 객관식 시험입니다 (16문항 이상 정답 시 통과). 각 문항 해설에 근거가 된 차시가 명시되어 있습니다.
