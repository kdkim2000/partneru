## 폴더별 구성 파일

각 과정 폴더에는 다음과 같은 자료가 포함됩니다.

- **강의 영상(.mp4)**: 차시별 강의 콘텐츠 (한국어 더빙/자막)
- **강의 노트(.md)**: 차시별 핵심 내용 요약 노트 (영문 원본 기준 파일명)
- **워크시트/리플렉션 가이드(.pdf)**: 실습 및 회고 작성용 보조 자료
- **최종 시험(Final Exam)**: 각 과정 마지막 차시에 해당하는 노트/영상

## 학습 순서 권장

1. 관심 있는 전문가 트랙(ChatGPT / Codex / API)을 선택합니다.
2. 표에 나열된 순서대로 각 과정 폴더에 진입하여 차시 번호 순으로 학습합니다.
3. 영상 시청 후 동일 차시의 강의 노트(.md)로 핵심 내용을 복습합니다.
4. 워크시트/리플렉션 가이드가 있는 차시는 실습을 진행합니다.
5. 각 과정의 최종 시험(Final Exam) 자료로 마무리합니다.
